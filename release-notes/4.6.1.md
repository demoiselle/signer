# Release Notes - Demoiselle Signer

## Versão 4.6.1 (15/07/2026)

Esta versão foca na correção do processo de publicação para o **Sonatype Central** (Maven Central) e na consolidação das melhorias introduzidas na 4.6.0.

### 🚀 Publicação e Infraestrutura
- **Sonatype Central:** Ajuste nos metadados de todos os módulos (`licenses`, `developers`, `scm`) para atender aos novos requisitos de validação do Maven Central.
- **Maven Plugins:** Downgrade estratégico do `central-publishing-maven-plugin` para a versão `0.6.0` para garantir estabilidade no deploy multi-módulo.
- **Automação:** Adição do script `publicador.go` para realizar o deploy individual de cada módulo, garantindo que as coordenadas sejam resolvidas corretamente pelo validador.
- **Sincronização:** Atualização do módulo `policy-engine` para a versão 4.6.1, garantindo paridade em todo o ecossistema.

## Versão 4.6.0 (Junho/2026)

Uma versão maior com atualizações críticas de segurança, suporte a novos padrões da ICP-Brasil e melhorias na robustez de validação.

### 🛡️ Segurança e Dependências
- **Bouncy Castle:** Upgrade para a versão **LTS 2.73.11**. Refatoração de código ASN.1 para compatibilidade com as mudanças da biblioteca.
- **XMLSec:** Atualização para a versão **2.3.5** para correções de segurança e melhorias em XMLDSig/XAdES.
- **Commons-IO:** Atualização para a versão **2.15.1**.

### 🇧🇷 ICP-Brasil e Assinatura Digital
- **Raiz v12:** Suporte completo à nova Autoridade Certificadora Raiz da ICP-Brasil (v12).
- **Políticas v2.4/v2.5:** Suporte nativo às novas políticas de assinatura CAdES, XAdES e PAdES.
- **Resolução 211:** Implementação do suporte aos novos perfis de certificados introduzidos pela Resolução 211 da ICP-Brasil, incluindo suporte a Selo Eletrônico.
- **Refatoração do CAManager:** Reescrita completa do motor de construção de cadeias de certificação para ser mais robusto contra inconsistências de emissores.

### 🛠️ Correções e Melhorias
- **PAdES:** Melhoria na detecção de assinaturas em PDFs e suporte a validação com raízes v12.
- **XAdES:** Busca flexível de elementos via namespaces, melhorando a interoperabilidade com diferentes geradores de XML.
- **CAdES:** Tratamento de campos opcionais ETSI para evitar `NullPointerException`.
- **Performance:** Cache de `SSLContext` para conexões HTTPS via ICP-Brasil.
- **Timeouts:** Aumento dos tempos limites padrão para download de cadeias e CRLs para maior resiliência em redes instáveis.

### 🤖 Ferramentas e Automação
- **Automação de Artefatos:** Nova ferramenta em Go (`automacao-importador`) para atualização automática de cadeias (`.der`, `.bks`) e políticas (`.xml`).
- **Testes Multi-Versão:** Script para execução de testes em todas as versões LTS do Java (8, 11, 17, 21).
- **Isolamento de Testes:** Migração de testes de integração para o plugin `maven-failsafe`, ativado via perfil `-Pit`.
